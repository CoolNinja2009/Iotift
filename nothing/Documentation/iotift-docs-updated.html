IOTIFT

Minimal IoT language. Hardware-first syntax. Non-blocking by default. Compiles to optimized C for ESP32. One-command flash workflow.

ESP32 Native PlatformIO Ready Auto Port Detect
Introduction

What is IOTIFT?

Domain-specific language for IoT/microcontroller programming. Reads like pseudocode, compiles to production C.

No manual timers, interrupts, state machines. LED = 0 after 200; generates non-blocking scheduler automatically.

Core philosophy: Replace common IoT C boilerplate with one clean line.
rgb.iot
pin R = pwm 13;
pin G = pwm 12;
pin B = pwm 14;

float t = 0.0;

every 10 {
    t = millis();
    R = sin(t * 0.001);
    G = sin(t * 0.001 + 2.09);
    B = sin(t * 0.001 + 4.18);
}
Setup

Installation

Python 3.10+. No dependencies - compiler auto-installs PlatformIO/pyserial.

bash
# download iotift.py + supporting files
python iotift.py led.iot --flash
One command deploys: Generates project, auto-detects ESP32 port, builds, flashes. Auto-installs everything.
CLI

Compiler Reference

bash
python iotift.py INPUT.iot [options]

Basic:
  -o FILE        Output C file (default: generated.c)
  --device NAME  Target (esp32 default)
  --ast          Debug AST dump

PlatformIO:
  --project      Generate PlatformIO project folder
  --flash        Project + build + flash
  --port PORT    Serial port (auto-detects ESP32)

PlatformIO Workflow

--flash creates complete PlatformIO project, builds optimized firmware, flashes ESP32. Auto-installs PlatformIO if missing.

bash
python iotift.py led.iot --flash
# ✓ PlatformIO installed (first time only)
# ✓ ESP32 found on COM3 (auto)
# ✓ generated PlatformIO project: led_project/
# Building and flashing to COM3...
# ✓ flashed to device
Generated structure: project/platformio.ini + src/main.cpp (your compiled C).
Examples

RGB Rainbow LED

PWM sine wave animation at 100Hz. Raw ESP32 LEDC setup via C block.

led.iot
@device esp32

pin R = pwm 13;
pin G = pwm 12;
pin B = pwm 14;

float t = 0.0;

c setup {{
    ledcSetup(0, 5000, 8);
    ledcSetup(1, 5000, 8);
    ledcSetup(2, 5000, 8);
    ledcAttachPin(13, 0);
    ledcAttachPin(12, 1);
    ledcAttachPin(14, 2);
}}

every 10 {{
    t = millis();
    R = sin(t * 0.001);
    G = sin(t * 0.001 + 2.09);
    B = sin(t * 0.001 + 4.18);
}}

python iotift.py led.iot --flash → smooth RGB rainbow.

Language

@device

Target HAL selection.

@device esp32

Pins

Automatic pinMode() + gpio write/read.

pin LED  = output  13;
pin BTN  = input   5;
pin TEMP = analog 34;
pin PWM  = pwm    18;

C Blocks

Raw C injection: c setup { ... }

c setup {{
    ledcSetup(0, 5000, 8);
}}
c loop {{
    // custom code
}}

Math Functions

Built-in : sin, cos, tan, sqrt, abs, pow, floor, ceil, round, log, exp.

r = sin(t * 0.001);
g = pow(2, temp);

Events • Timers • After

Non-blocking event handlers and timers. Auto-generated.

on BTN.press {{ LED = 1; }}
on BTN.release {{ LED = 0; }}
every 1000 {{ count++; }}
every 500 as ticker {{ stop ticker; }}
LED = 0 after 200;

Budget Horn Controller

horn.iot
@device esp32
pin BTN = input 4;
pin BUZZ = output 18;

const 30s BUDGET = 30000;

int used = 0;

on BTN.press {{
    BUZZ = 1;
}}

every 1s {{
    used += 1000;
    if (used > BUDGET) BUZZ = 0;
}}
