IOTIFT

Minimal IoT language. Hardware-first syntax. Non-blocking by default. Compiles to optimized C for ESP32. One-command flash workflow.

ESP32 Native PlatformIO Ready Auto Port Detect
Introduction

What is IOTIFT?

Domain-specific language for IoT/microcontroller programming. Reads like pseudocode, compiles to production C.

No manual timers, interrupts, or state machines. LED = 0 after 200; generates non-blocking scheduler automatically.

Core philosophy: Replace common IoT C boilerplate with one clean line.
rgb.iot
pin R = pwm 13;
pin G = pwm 12;
pin B = pwm 14;

float t = 0.0;

every 10 {
    t = millis();
    R = sin(t * 0.001);
    G = sin(t * 0.001 + 2.09);
    B = sin(t * 0.001 + 4.18);
}
Setup

Installation

Python 3.10+. No dependencies - compiler auto-installs PlatformIO/pyserial.

bash
# download iotift.py + supporting files
python iotift.py led.iot --flash
One command deploys: Generates project, auto-detects ESP32 port, builds, flashes. Auto-installs everything.
CLI

Compiler Reference

bash
python iotift.py INPUT.iot [options]

Basic:
  -o FILE        Output C file
  --device NAME  Target (esp32 default)
  --ast          Debug AST dump

PlatformIO:
  --project      Generate PlatformIO project
  --flash        Project + build + flash
  --port PORT    Serial port (auto-detects)

PlatformIO Workflow

--flash creates complete PlatformIO project, builds optimized firmware, flashes ESP32.

bash
python iotift.py led.iot --flash
# ✓ PlatformIO installed
# ✓ ESP32 found on COM3
# ✓ Building and flashing...

LED = 1;
LED = 0 after 200;

Events

on BTN.press {{ LED = 1; }}
on TEMP > 50 {{ FAN = 1; }}

Every — Timers

every 1000 {{ count++; }}
every 500 as ticker {{ stop ticker; }}

Budget Horn Controller

horn.iot
@device esp32
pin BTN = input 4;
pin BUZZ = output 18;

const 30s BUDGET = 30000;

on BTN.press {{
    BUZZ = 1;
}}

every 1s {{
    used += 1000;
    if (used > BUDGET) BUZZ = 0;
}}
