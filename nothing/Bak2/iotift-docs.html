IOTIFT

A minimal, expressive programming language for IoT. Write hardware logic in plain English. Compile to C.

Turing Complete Non-Blocking by Default Compiles to C
01 — Introduction

What is IOTIFT?

IOTIFT is a domain-specific language built for microcontrollers. Instead of fighting with C timers, interrupt flags, and state machines, you write what you mean — and the compiler handles the rest.

A statement like LED = 0 after 200; looks simple. Under the hood the compiler generates a non-blocking scheduled timer, a state flag, and a handler function — automatically. You never write delay().

Design philosophy: Every ugly C pattern that every IoT developer rewrites from scratch should be one clean line in IOTIFT.
iotift
// This is all you need for a button-controlled blinking LED
pin LED = output 12;
pin BTN = input  5;

on BTN.press {
    LED = 1;
    LED = 0 after 200;
}
02 — Setup

Installation

IOTIFT requires Python 3.10 or higher. No external dependencies.

shell
# clone or download the compiler files
git clone https://github.com/yourname/iotift

# the compiler is a single command
python iotift.py your_program.iot -o output.c

The compiler produces a single .c file you can drop into Arduino IDE, PlatformIO, or compile with gcc for PC simulation.

03 — First Program

Hello World

The IOTIFT equivalent of hello world is a blinking LED.

blink.iot
@device esp32

pin LED = output 13;

    LED = 1;

Compile and flash it:

shell
python iotift.py blink.iot -o blink.c --device esp32

Language

Device Target

Declare your target hardware at the top of the file. This tells the compiler which HAL functions and timing primitives to use.

iotift
@device esp32
@device esp32
@device esp32
@device rpi_pico
Note: The @device declaration is optional. If omitted, the compiler defaults to arduino_uno compatible output.

Pins

Pins are the primary way to interact with hardware. Declare them at the top of your file.

iotift
pin LED  = output  12;   // digital output
pin BTN  = input   5;    // digital input
pin TEMP = analog  34;   // analog input (ADC)
pin SDA  = i2c     21;   // I2C data
pin SCL  = i2c     22;   // I2C clock
pin FAN  = pwm     18;   // PWM output

Syntax: pin NAME = direction NUMBER;

DirectionUseCompiles to
outputLEDs, relays, motorspinMode(PIN, OUTPUT)
inputButtons, switchespinMode(PIN, INPUT)
analogSensors, potentiometerspinMode(PIN, INPUT)
i2cI2C devicesHAL I2C init
spiSPI devicesHAL SPI init
pwmServos, dimmerspinMode(PIN, OUTPUT)

Once declared, pin names work as first-class identifiers — use them directly in assignments and events.

Assignment

Assign values to variables or pins. Assigning to a pin name automatically calls the correct HAL function.

iotift
// variable
count = 10;
count = count + 1;

// pin — calls gpio_set_level() automatically
LED = 1;    // HIGH
LED = 0;    // LOW

// compound
count += 1;
count -= 1;
count *= 2;
count /= 4;

After — Non-Blocking Delay

The after keyword is one of IOTIFT's most important features. It schedules a pin or variable assignment to happen after a delay, without blocking the main loop.

iotift
LED = 0 after 200;     // turn off after 200 ms
LED = 0 after 2000;    // turn off after 2000 ms (2 seconds)
All delays are in milliseconds. There is no other unit. This keeps programs unambiguous and prevents bugs.

The difference versus a blocking delay:

comparison
// ❌ BAD — blocks everything for 200ms
LED = 1;
delay(200);
LED = 0;

// ✅ GOOD — returns immediately, schedules the OFF
LED = 1;
LED = 0 after 200;

Loops

loop — infinite

iotift
loop {
    count += 1;
}

while

iotift
while (count < 10) {
    count += 1;
}

for

iotift
for (int i = 0; i < 5; i += 1) {
    LED = 1;
    LED = 0 after 100;
}

Use break to exit any loop, and continue to skip to the next iteration.

Events

Event blocks run automatically when a pin changes state. The compiler generates all the edge-detection boilerplate for you.

iotift
// fires once when BTN goes LOW→HIGH
on BTN.press {
    LED = 1;
}

// fires once when BTN goes HIGH→LOW
on BTN.release {
    LED = 0;
}

// fires on any change
on BTN.change {
    LED = BTN;
}

// analog threshold events
on TEMP > 50 {
    FAN = 1;
}

on TEMP < 30 {
    FAN = 0;
}
EventTriggers when
.pressPin goes from LOW to HIGH (rising edge)
.releasePin goes from HIGH to LOW (falling edge)
.changePin value changes in either direction
> valueAnalog reading exceeds threshold
< valueAnalog reading drops below threshold

Every — Periodic Timers

Run a block of code on a fixed interval, non-blocking. All times are in milliseconds.

iotift
// runs every 1000ms
every 1000 {
    count += 1;
    print(count);
}

// named timer — can be stopped from inside
every 500 as ticker {
    count += 1;
    if (count == 20) {
        stop ticker;     // stops this timer permanently
    }
}
Named timers with as label can be stopped using stop label; from inside the timer body. Once stopped, the timer never fires again.

Functions

iotift
// void function
fn blink(int times) {
    for (int i = 0; i < times; i += 1) {
        LED = 1;
        LED = 0 after 200;
    }
}

// function with return value
fn clamp(int val, int lo, int hi) -> int {
    if (val < lo) { return lo; }
    if (val > hi) { return hi; }
    return val;
}

// calling functions
blink(3);
int safe = clamp(count, 0, 100);

Syntax: fn name(type param, ...) { } for void, or fn name(...) -> type { } for functions that return a value.

Extern Functions

Call vendor SDK functions or C functions from IOTIFT using extern fn.

iotift
// declare the extern at the top of your file
extern fn esp_restart();
extern fn esp_deep_sleep(int ms);
extern fn Serial_print(str msg);

// then call them normally
esp_restart();
esp_deep_sleep(60000);

Full Program

Temperature-controlled fan with LED status indicator and auto-restart after 100 cycles.

full.iot
@device esp32

// ── pins ──
pin LED  = output 12;
pin BTN  = input  5;
pin TEMP = analog 34;
pin FAN  = output 18;

// ── state ──
int   count   = 0;
float tempVal = 0.0;
bool  fanOn   = false;

// ── extern ──
extern fn esp_restart();

// ── events ──
on BTN.press {
    LED = 1;
    LED = 0 after 200;
}

// ── timers ──
every 1000 {
    count   += 1;
    tempVal = 25;
    print(count);

    if (tempVal > 50) {
        FAN   = 1;
        fanOn = true;
    } else {
        FAN   = 0;
        fanOn = false;
    }
}

// ── main loop ──
void loop() {
    if (count == 100) {
        print("restarting");
        esp_restart();
    }
}
